# Career Value ও Positioning

## Why This Learning Is Valuable for a Software Career

Accounting for Software Development শেখা বিশেষভাবে valuable যখন আপনি business software, ERP, HRM, Payroll, Asset, Hospital, School, Inventory, Finance বা enterprise applications নিয়ে কাজ করেন।

এই skill আপনাকে শুধু feature implementation থেকে ধীরে ধীরে domain-aware engineering এবং architecture-level thinking-এর দিকে নিয়ে যায়।

### Career Value Estimate

| Skill / Capability | Career Value |
|---|---:|
| শুধু Frontend / CRUD Development | 6/10 |
| Backend + Business Logic | 8/10 |
| **Accounting Domain + Software Architecture** | **9/10** |
| **Accounting + ERP Architecture + Strong Backend/System Design** | **9.5/10** |

এই rating কোনো formal industry score নয়; এটি learning priority এবং practical leverage বোঝানোর জন্য একটি qualitative estimate।

```text

→ API
→ Database Update
```

Accounting-aware developer / architect চিন্তা করবে:

```text

→ Payroll Posting
→ Salary Payable
→ Tax / PF Liability
→ Bank Payment
→ Journal
→ Ledger
→ P&L / Balance Sheet
→ Reconciliation
```

এই difference-টাই আপনাকে শুধু feature builder না রেখে business-domain-aware engineer হিসেবে grow করতে সাহায্য করে।

## Recommended Learning Balance

Pure accounting theory-তে পুরো সময় না দিয়ে software implementation এবং architecture-এর সাথে parallelভাবে শিখুন।

Recommended split:

| Learning Area | Recommended Share |
|---|---:|
| Accounting Concepts | **40%** |
| Accounting Software Architecture | **35%** |
| Implementation / Practice | **25%** |

এই balance-এর উদ্দেশ্য:

```text
Accounting বুঝবেন
        +
Architecture design করবেন
        +
নিজে implement/test করবেন
```

শুধু journal entry মুখস্থ করা বা শুধু database schema তৈরি করা—কোনোটাই একা যথেষ্ট নয়।

## Approximate Time Investment

যদি প্রতিদিন প্রায় 2 ঘণ্টা study করেন:

```text
2 hours/day × approximately 180 days
≈ 360 hours
```

**330–360+ focused learning hours**

এই সময়ের মধ্যে theory, exercises, architecture design, database modeling এবং capstone implementation অন্তর্ভুক্ত থাকবে।

## What Not to Do

এই roadmap follow করার সময় কিছু common mistake avoid করুন:

- Accountant certification-level detail দিয়ে শুরু করবেন না
- Journal entries শুধু মুখস্থ করবেন না
- Account IDs hard-code করার habit তৈরি করবেন না
- Accounting logic UI/API controller-এ ছড়িয়ে দেবেন না
- Posted journal edit/delete করা normal behavior ধরে নেবেন না
- Business workflow এবং financial posting-কে একই জিনিস মনে করবেন না
- Subledger reconciliation skip করবেন না
- শুধু theory পড়ে implementation না করা
- শুধু code করে financial statement impact না বোঝা
